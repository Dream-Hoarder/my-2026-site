# Security Policy (SECURITY.md)

Operating under a Zero-Trust paradigm means vulnerabilities are addressed proactively. If you discover a vulnerability or security misconfiguration in any system, script, or service in this repository, please report it immediately.

## Reporting a Vulnerability

1. **Email:** Send your report via encrypted email to: [willie.bonnerjr@outlook.com](mailto:willie.bonnerjr@outlook.com)
2. **PGP Key:** Verify and encrypt your message using my public PGP key. You can retrieve this block by running the `security` command in the interactive web terminal on my portfolio site.

Please include:
* Description of the vulnerability.
* Detailed steps to reproduce (PoC).
* Potential security impact.

## Disclosure Policy

* **Responsibility:** We follow responsible disclosure guidelines. Please give us reasonable time to patch the issue before making it public.
* **Response Time:** Initial response to valid submissions is targeted within 48 hours.
